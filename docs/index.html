A recipe score you can add up yourself.

Epicourier ranks recipes by what is already in your kitchen. Instead of a match percentage written by a language model, every recipe comes with a receipt: one line per pantry item, the points it earned, and a total that is exactly their sum.

Disagree with a line? Correct it, and watch the ranking move the way the rules say it should.

Run the evaluation Read why it exists
python3 p2/eval/run_eval.py

No install, no API key, no database. Runs in under a minute from a fresh clone.

Three claims, each one able to fail.

M0 came before the scorer. We stated what would have to be true for receipts to be trustworthy, set thresholds with zero tolerance, and wired the check into CI on every push. These are today's numbers.

ClaimResultOld recommender
H1 Every displayed total is the sum of its displayed parts.500 generated pantry and recipe cells, 6,120 receipt lines. 500/500threshold 100%, met 0/300. Its schema has no field that could hold a per-ingredient contribution.
H2 The same pantry gives the same answer.25 cells, each with its inventory shuffled 20 times. 25/25threshold 100%, met Not collected yet. It needs 30 live model calls, and we report it as missing rather than estimate it.
H3 A correction moves the score the way the rules predict.Top up, expire, fix a unit, move stock between shelves. The last must change nothing. 4/4threshold 100%, met No correction loop exists to compare against.

The harness also carries a case with four planted defects. CI checks that it is rejected on every run, so a green badge means the check can still see a broken receipt. How the evaluation works.

Built in four merged milestones.

Each one froze an interface for the next. The contract came first, so four people could build against it in parallel without drifting apart.

  1. M0

    Contract and evaluation

    A frozen JSON contract, a 500-cell corpus, and an offline harness in CI that scores against hand-written expectations.

    Wenbo Li, #20, #25
  2. M1

    Deterministic scorer

    A pure Python function that turns pantry and recipe into a receipt, with boundary, mutation and differential tests.

    Sihao Liu, #23, #24
  3. M2

    Receipt panel

    Expand any recommendation to see its lines, correct an item, and watch the list re-rank. Corrections survive a refresh.

    Jeffery, #22
  4. M3

    Shopping from the gap

    Preview exactly what is missing, then confirm once. A replayed request applies only once, enforced by the database.

    Andy, #21
