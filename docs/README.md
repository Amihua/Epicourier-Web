## Regenerating the API reference

Both are generated, and CI fails if either is stale.

```bash
python3 docs/generate_backend_api.py                       # backend, no dependencies
cd web && npx typedoc@0.27 --out ../docs/api/web \
  --entryPoints src/types/receipt.ts --readme none \
  --hideGenerator --githubPages false \
  --name "Epicourier receipt contract (TypeScript)"        # web
```

The backend generator reads source with `ast` and never imports it, because importing anything that
reaches `api/recommender.py:121` constructs a model client and fails without a key. A documentation
build that only works on a configured machine stops being run.
